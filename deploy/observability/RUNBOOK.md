# Java 网关告警处理

监控只连接受信任的内部网络，令牌文件使用专用低权限且允许读取指标的网关密钥，不使用供应商密钥。网关使用原始 TCP 对端身份；经过代理时先配置精确可信代理 CIDR。

不可用：检查 /livez、/actuator/health、PostgreSQL 和私密环境配置。高失败率：在请求日志按时间、Provider、错误码过滤，查看各次尝试和治理拒绝，不自动重放已输出流。高延迟：区分本地队列和上游耗时，检查 Provider 健康与超时。预算异常：对比账户与只追加账本，禁止直接改历史事件。

正式恢复前先运行 scripts/backup.ps1 -Action Verify，对新建临时数据库演练；Restore 仅接受全新 polygate_restore_* 目标。先暂停入口并等待流排空，再切换配置，不让新旧进程同时处理业务流量。备份包含账号哈希及业务记录，应留在私密目录。
